Projetos

Gateway de rastreio

Projeto desenvolvido para integrar diferentes serviços de operadores logísticos em um HUB, abstraindo as regras específicas de cada API e oferecendo uma integração simplificada para o cliente.

Saiba mais...(Clique Aqui)

Este projeto foi criado para resolver o desafio de integrar múltiplos serviços de rastreamento de encomendas, cada um com suas próprias APIs e regras de autenticação. O gateway atua como um intermediário, recebendo requisições do cliente e encaminhando-as para os serviços logísticos correspondentes, processando as respostas e retornando informações consolidadas ao cliente. O sistema é construído com uma arquitetura modular, permitindo fácil adição de novos serviços logísticos no futuro, e inclui recursos como cache de respostas para melhorar a performance e tratamento de erros para garantir a robustez da aplicação.

E-Commerce Dashboard

Sistema de gestão e visualização de pedidos, produtos e custos para e-commerce, com dashboard de métricas financeiras.

Saiba mais...(Clique Aqui)

Este projeto foi desenvolvido para atender a necessidade de um cliente de e-commerce que precisava de visibilidade sobre suas operações financeiras. O sistema permite:

  • Visualizar métricas consolidadas (faturamento, custos, lucro)
  • Cadastrar produtos com preços de venda
  • Registrar custos de produção de cada produto
  • Receber pedidos via webhook de plataformas externas
  • Filtrar dados por período
  • Calcular lucro automaticamente
